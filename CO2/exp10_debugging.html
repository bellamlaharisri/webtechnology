Temperature Converter — Debug Log

A small app with two real bugs found and fixed using Chrome DevTools

→

Debugging Notes (DevTools Workflow)

  • Elements panel: inspected .converter-box and found its rendered width exceeded the parent panel. The Computed tab showed padding was being added on top of the 100% width. Fixed by setting box-sizing: border-box globally.
  • Console panel: converting a value returned NaN. Added console.log(rawValue, parsedValue) at the top of convertTemperature() to trace the value — it revealed parseFloat() was never called on the input, so a string was being used in arithmetic.
  • Sources panel: set a breakpoint on the conversion line and stepped through with the debugger; keyword (left in place below, commented) to confirm the fixed formula produces the correct result before removing the breakpoint.
  • Error handling: wrapped the parsing logic in a try...catch block so an invalid or empty input shows a friendly on-screen message instead of a silent console error.
